# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's **Report a vulnerability** button under the repository's
**Security** tab (private vulnerability reporting). Include what you found, how to reproduce it and what it could allow.

You can expect an acknowledgement within a few days. Fixes are released as soon as they are ready, and you will be credited if you wish.

## What is in scope

- The website and its code in this repository.
- The Content-Security-Policy, security headers, service worker and the files the app reads (saved games, backup files, fonts, pictures).

## What the app stores

The app has no accounts and no server-side storage. Games, statistics and settings live in the visitor's browser; books and
exports are created on the visitor's device. See the privacy page in the app for details.
